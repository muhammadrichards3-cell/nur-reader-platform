# Nūr Reader Platform

Building Readers. Inspiring Generations.

The Nūr Reader Platform is a reader-centred management system developed for the Islamic Mobile Library initiative by Two Lights Academy.

## Mission

To inspire a lifelong love of reading through intuitive software that supports children, families, volunteers, and community libraries.
